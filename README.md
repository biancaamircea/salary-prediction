# Salary Prediction and Vacation Classification

Academic Python project by Bianca-Anastasia Mircea, April–May 2026.

Exploratory analysis and preprocessing of tabular employment data, followed by vacation classification and salary regression. The notebook compares decision trees, logistic regression, linear regression and Ridge regression, plots evaluation results, and exports CSV predictions.

## Files and environment

- `tema.ipynb`: original code, with saved outputs and execution counters cleared for publication.
- `tema.pdf`: original report.
- `requirements.txt`: imported third-party packages, without unverified version pins.

Install the dependencies in a virtual environment, then open the notebook in Jupyter. Supply the external course datasets referenced by the notebook, including `CC_education_economy_train.csv`, `CC_education_economy_test.csv` and `CC_private_test.csv` in the expected location. Datasets are not included in the archive. Outputs can be regenerated only with the datasets and a compatible environment. The notebook was inspected but not retrained during preparation.
